# Cookie Policy / 쿠키 정책

Effective: {{EFFECTIVE_DATE}}

## What cookies we use

| Name | Purpose | Duration | Category |
|---|---|---|---|
| `sb-access-token` | Supabase session | Session | Strictly Necessary |
| `sb-refresh-token` | Supabase refresh | 7 days | Strictly Necessary |
| `NEXT_LOCALE` | Language preference (ko/en) | 1 year | Functional |
| `theme` | Light/dark mode | 1 year | Functional |
| `_va` (Vercel Analytics) | Aggregated page views | 1 year | Analytics (opt-in EEA) |
| `_sentry` | Error session ID | Session | Strictly Necessary |

## 쿠키 목적

1. **필수 쿠키** — 로그인 유지, 보안 토큰. 거부 시 서비스 이용 불가.
2. **기능 쿠키** — 언어·테마 선호 저장. 거부 시 매번 재설정 필요.
3. **분석 쿠키** — 집계된 트래픽 분석. EEA 사용자에게만 배너 동의 후 수집.

## Managing cookies

- **In-app**: Footer → "쿠키 설정" / "Cookie settings"
- **Browser**: Each browser allows you to block or delete cookies. See
  [aboutcookies.org](https://www.aboutcookies.org/) for guides.

Rejecting strictly-necessary cookies will prevent you from logging in.
