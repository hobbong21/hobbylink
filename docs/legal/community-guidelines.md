# Community Guidelines / 커뮤니티 가이드라인

## 우리가 지향하는 것

HobbyLink는 **취미로 연결되는 오프라인 모임**을 만드는 공간입니다. 안전하고
포용적이며 서로 존중하는 분위기를 유지하기 위해 모든 회원에게 아래 원칙을
요청합니다.

## 허용되는 행동

- 관심사 기반 건설적인 대화
- 모임 후기·사진·팁 공유
- 서로의 경계를 존중하는 소통
- 다양한 배경·능력·경험에 대한 포용

## 허용되지 않는 행동

### 1. 괴롭힘·혐오
- 성별·인종·국적·종교·성적 지향·장애를 이유로 한 차별·모욕
- 반복적 사적 메시지, 스토킹, 위협

### 2. 성적 괴롭힘
- 원치 않는 성적 접근·내용·이미지 전송
- 상대방 신체에 대한 평가·코멘트
- 아동 관련 성적 콘텐츠 (즉시 경찰 신고)

### 3. 사기·스팸
- 다단계·피라미드·암호화폐 투자 유치
- 타인 금전 편취, 대출 권유
- 허위 모임 개설, 미성사 시 환불 거부

### 4. 범죄 유도
- 마약·도박·성매매 관련 만남
- 폭력·자해·자살 조장

### 5. 플랫폼 악용
- 다계정 운영, 자동화 도구(봇·매크로) 사용
- 회사 권한 사칭, 피싱 사이트 링크 유포

## 위반 시 조치

위반 유형과 정도에 따라 다음 중 하나 이상의 조치가 적용됩니다.

| 단계 | 조치 |
|---|---|
| 경고 | 서면 경고 + 관련 콘텐츠 삭제 |
| 일시정지 | 7일 ~ 30일 계정 이용 제한 |
| 영구정지 | 계정 영구 삭제, 재가입 차단 |
| 법적 조치 | 형사 고발, 민사 손해배상 청구 |

## 신고 방법

- 앱 내 **플래그** 아이콘 → 사유 선택 → 제출
- 이메일 {{SUPPORT_EMAIL}}
- 긴급(범죄): 경찰청 **112** / 사이버수사국 **182**

회사는 **24시간 이내** 초동 대응하며, 신고인·피신고인 양측의 프라이버시를
보호합니다.

## 이의 제기

제재를 받은 회원은 **30일 이내** {{SUPPORT_EMAIL}}로 이의를 제기할 수
있습니다. 회사는 14일 이내 재심사 결과를 통지합니다.
