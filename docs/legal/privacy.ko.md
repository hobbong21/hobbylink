# 개인정보처리방침

{{COMPANY_NAME}}(이하 "회사")는 이용자의 개인정보를 중요시하며, 개인정보보호법
및 정보통신망 이용촉진 및 정보보호 등에 관한 법률을 준수합니다.

## 1. 개인정보의 처리 목적

회사는 다음의 목적을 위하여 개인정보를 처리합니다.

| 구분 | 목적 |
|---|---|
| 회원관리 | 회원제 서비스 제공, 본인확인, 부정이용 방지, 가입의사 확인, 분쟁조정을 위한 기록 보존 |
| 서비스 제공 | 관심사 매칭, 오프라인 모임 개설·참여, 메시지 송수신, 콘텐츠 추천 |
| 결제 | 유료 서비스 결제, 환불 처리, 세금계산서 발급 |
| 마케팅 | 이벤트 정보 제공, 광고성 정보 전송 (별도 동의 시) |
| 고객지원 | 문의·신고 처리, A/S 응대 |

## 2. 처리하는 개인정보 항목

### (1) 회원가입 시 필수 수집
- 이메일, 비밀번호 (암호화 저장)
- 닉네임(표시명), 생년월일, 성별
- 거주 지역 (시/도 단위)

### (2) 서비스 이용 중 수집
- 관심사, 자기소개, 프로필 사진
- 모임 참여 기록, 메시지 내용, 후기
- 접속 로그, IP 주소, 쿠키, User-Agent
- 위치 정보 (모임 검색 기능 사용 시, 선택)

### (3) 유료 서비스 결제 시
- 결제 수단 정보(카드 번호의 뒤 4자리, 카드사명)
- 실제 카드 전체 번호는 PG사(Stripe)가 보관하며 회사는 저장하지 않음

### (4) 전화번호 인증 시
- 휴대전화번호 (Twilio 전송, 인증 후 hash만 보관)

### (5) 자동 생성 정보
- 서비스 이용 내역, 쿠키, 접속 IP
- 단말기 정보(OS, 브라우저 종류)

## 4. 개인정보의 제3자 제공

회사는 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 단, 아래의
경우 예외입니다.

- 이용자가 사전에 동의한 경우
- 법령의 규정에 의거하거나 수사 목적으로 수사기관의 영장에 의한 요구가
  있는 경우

## 5. 개인정보처리의 위탁

서비스 제공을 위해 다음과 같이 처리를 위탁합니다.

| 수탁자 | 위탁 업무 | 보관 위치 |
|---|---|---|
| Supabase (Supabase Inc.) | 데이터베이스·인증·파일 저장 | AWS 서울 리전 |
| Vercel (Vercel Inc.) | 웹 호스팅·CDN | 글로벌 |
| Resend (Resend Inc.) | 트랜잭션 이메일 발송 | 미국 |
| Twilio (Twilio Inc.) | SMS 본인인증 | 미국 |
| Stripe (Stripe, Inc.) | 결제 처리 | 미국 |
| Sentry (Functional Software, Inc.) | 오류 모니터링 | 미국 |
| Kakao | 지도 서비스 | 한국 |

각 수탁사는 표준계약조항(SCC) 및 GDPR/CCPA 준수 합의에 서명되어 있습니다.
전체 목록은 [sub-processors](/sub-processors) 페이지 참조.

## 6. 국외 이전

일부 위탁사(Vercel·Resend·Twilio·Stripe·Sentry)는 미국·EU 등에 서버를
운영합니다. 이전되는 정보·이전 국가·이전 목적·보유기간·거부권 등은 위
5항 표에 명시되어 있습니다.

이용자는 국외 이전에 대한 동의를 거부할 권리가 있으나, 거부 시 일부 서비스
(이메일 발송·SMS 인증·결제 등) 이용이 제한될 수 있습니다.

## 7. 이용자 권리와 행사 방법

이용자는 언제든지 다음 권리를 행사할 수 있습니다.

- 개인정보 **열람** 요구
- **정정·삭제** 요구
- **처리정지** 요구
- **동의철회** 및 회원탈퇴

### 행사 방법
1. `/settings` 페이지의 프로필 수정 / 데이터 내보내기 / 탈퇴 기능
2. {{DPO_EMAIL}} 로 이메일 요청
3. 우편·팩스 등 서면 요청

회사는 요청 접수 후 **10일 이내** 처리하며, 불가 시 그 사유를 통지합니다.

## 8. 개인정보의 파기

이용자가 회원탈퇴 또는 보유기간이 만료된 개인정보는 복구가 불가능한 방법으로
즉시 파기합니다.

- 전자적 파일: 안전한 삭제(wipe)
- 종이 문서: 분쇄기 파쇄 또는 소각

## 9. 개인정보의 안전성 확보 조치

회사는 다음의 기술적·관리적 조치를 시행합니다.

- 개인정보 접근권한 최소화 및 관리
- 비밀번호 bcrypt 암호화, 통신 TLS 1.3
- 개인정보 취급 직원 대상 정기 교육
- 침입 차단 시스템·로그 모니터링
- 개인정보 처리시스템 접근기록 1년 보관
